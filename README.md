# CampusRoute: Explainable Campus Commute Decision App

**CampusRoute** is a route planning app that allows the user to effectively plan routes to their college campus. It compares various routes of transportation, such as by bus, train, or backup ride. The tool also explains which method of transportation meets the user's budget & priorities the most, such as going to campus by walking, by bus ride, train, or by backup ride. 

CampusRoute also allows the user to enter a wide variety of parameters, such as their departure time, arrival deadline, budget, walk time & limits, current weather, and much more. Decisions are also displayed visually, through a truth table, decision tree, and knowledge graph.

## Features

* **Define Desired Commute Budget, Times, and Priorities:** Allows the user to define desired constraints such as the time they want to arrive at campus, how much of a budget they have to spend on campus transportation, and how far they can walk. 

* **Compares Specific Methods of Transportation, Constraints, and Transportation Times:** The user can also choose which methods of transportation are available, such as riding by backup ride, bus, or train to compare for the best result. The user can also set the fares and the time it takes to walk to campus for each method, allowing them to find the cheapest form of transportation for their budget.

* **Visual Integration:** Presents the result through propositional logic, a truth
table, an expression tree, a decision tree, and a knowledge graph, rather than receiving only a black-box answer.

* Java (version 25 or higher)

1. Navigate to the **project directory:**
   ```bash
   cd scenario-a-group-project-main
   ```

2. Compile & Run the `Main.java` file inside the `src/` folder.
   ```bash
   java ./src/Main.java
   ```
